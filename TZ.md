\# Техническое задание на проект: Reading Planner



\## 1. Цель проекта

Создание веб-сервиса для планирования чтения учебной литературы студентами. Система помогает равномерно распределить нагрузку по дням до дедлайна, отслеживать прогресс и корректировать темп на основе фактически прочитанных страниц.



\## 2. Роли пользователей

\- \*\*Гость\*\*: просмотр публичных примеров планов чтения, ознакомление с функционалом.

\- \*\*Авторизованный пользователь (Студент)\*\*: добавление книг, создание планов, внесение сессий чтения, просмотр аналитики прогресса.

\- \*\*Администратор\*\*: управление всеми данными через Django Admin, модерация контента.



\## 3. Модели данных (сущности)



\### Book (Книга)

Карточка учебной литературы.

\- `title` (CharField): название книги

\- `author` (CharField): автор

\- `total\_pages` (PositiveIntegerField): общее количество страниц

\- `deadline` (DateField): дата, к которой нужно закончить чтение

\- `external\_id` (CharField, blank=True): идентификатор из OpenLibrary API

\- `user` (ForeignKey to User): привязка к владельцу



\### ReadingPlan (План чтения)

Распределение страниц по дням.

\- `book` (OneToOneField to Book): ссылка на книгу

\- `start\_date` (DateField): дата начала чтения

\- `daily\_target` (PositiveIntegerField): целевое количество страниц в день

\- `is\_active` (BooleanField): статус плана (активен/завершён)



\### ReadingSession (Сессия чтения)

Факт прочтения части книги.

\- `book` (ForeignKey to Book): к какой книге относится

\- `date` (DateField): дата сессии

\- `pages\_read` (PositiveIntegerField): сколько страниц прочитано

\- `notes` (TextField, blank=True): заметки пользователя



\*\*Связи\*\*: 

\- Book 1:1 ReadingPlan (одна книга — один активный план)

\- Book 1:N ReadingSession (одна книга — много сессий чтения)



\## 4. Ключевой функционал (User Stories)

1\. \*\*Добавление книги\*\*: Пользователь вводит название книги → система через OpenLibrary API подтягивает количество страниц и автора → создаётся запись в БД.

2\. \*\*Генерация плана\*\*: После указания дедлайна система автоматически рассчитывает ежедневный темп (остаток страниц / остаток дней) и сохраняет в ReadingPlan.

3\. \*\*Отчёт о прогрессе\*\*: При добавлении ReadingSession система пересчитывает оставшийся объём, сравнивает план/факт через Pandas и показывает, отстаёт пользователь или опережает график.

4\. \*\*Визуализация\*\*: На странице книги отображается график прогресса (Plotly): плановая линия vs фактические точки сессий.



\## 5. Внешние интеграции и аналитика

\- \*\*Интеграция\*\*: OpenLibrary Search API (`https://openlibrary.org/search.json?title=...`) для автозаполнения метаданных книги.

\- \*\*Аналитика\*\*: 

&#x20; - `Pandas` для расчёта скользящего среднего темпа, отклонения от плана, прогноза даты завершения.

&#x20; - `Plotly` для отрисовки интерактивного графика "План vs Факт" на странице книги.
