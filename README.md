#  Reading Planner

**Планировщик чтения и анализа прогресса освоения литературы для студентов**

Система помогает равномерно распределить нагрузку по чтению, отслеживать прогресс и визуализировать результаты с помощью интерактивных графиков.

 **Рабочая версия:** [ссылка будет после деплоя]

## Технологии

- **Backend:** Python 3.14, Django 4.2
- **База данных:** SQLite (разработка), PostgreSQL (продакшн)
- **Аналитика:** Pandas (расчёт прогресса), Plotly (визуализация)
- **Frontend:** Bootstrap 5, HTML5
- **API:** OpenLibrary (автозаполнение метаданных книг)

## Функционал

Добавление книг с автоматическим подтягиванием данных из OpenLibrary  
Создание плана чтения с расчётом ежедневной нормы  
Отслеживание сессий чтения  
Интерактивные графики прогресса (Plotly)  
Анализ темпа чтения с помощью Pandas  
Адаптивный дизайн (Bootstrap 5)
